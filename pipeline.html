How to run a stage

  1. Click the corresponding workflow button.
  2. On GitHub, click Run workflow.
  3. Choose the matching value in the stage dropdown.
  4. Click Run workflow again and inspect each step's logs.
  5. Review the candidate PR or branch. Merge only after checking headlines, dates, sources and timelines.

Manual dispatch requires the workflow to be present on the default branch. See GitHub's documentation.
